# 방명록 시작 폴더

1일차 4교시를 시작하는 폴더예요. 이 폴더를 수업 저장소 밖(예: `~/dbinc-work/praise-relay`)으로 복사해서, 이름을 내 주제로 바꾸고 Claude 데스크톱 앱의 Code 탭에서 열어요.

| 파일 | 하는 일 |
| --- | --- |
| `.claude/skills/prd-interview/SKILL.md` | 인터뷰 모드 스킬이에요. Code 탭에서 Plan 모드로 바꾸고 입력창에 `/prd-interview 내 주제`를 보내면, Claude가 질문 카드로 하나씩 묻고 `PRD.md`를 만들어요 |
| `index.html` | Python 길에서 쓰는 시작 화면이에요. 입력칸은 있지만 저장은 안 돼요. React 길에서는 쓰지 않아요 |
| `.gitignore` | DB 파일, `node_modules`, 빌드 결과, `.env` 파일을 커밋하지 않게 해요 |

만드는 순서는 [4교시 교안](../../../docs/day1-guestbook.md)과 [단계별 요청 모음](../REQUIREMENTS-PROMPTS.md)을 따라요.
